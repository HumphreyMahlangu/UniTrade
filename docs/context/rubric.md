## The two criteria that depend on this code
**Artefact — complete working application (10%)**
- Proficient (75–100%): fully operational application that meets all requirements; flawless execution with robust error handling and no bugs.
- Competent (50–75%): complete and working application with minor bugs; handles main user flows successfully but lacks deep error handling.
- Requires improvement (25–50%): partially working application; core features function but frequent crashes, bugs, or missing logic disrupt use.
- Unacceptable (0–25%): non-functional or incomplete application; fails to execute core tasks or crashes immediately upon deployment.

**Presentation / Demo (15%)**
- Proficient: concise walkthrough under 10 minutes in MP4; clearly highlights all system features with crisp audio, smooth transitions, seamless workflow demonstration.
- Competent: complete walkthrough in MP4 meeting the time limit; demonstrates most features clearly, though audio levels or pacing are slightly inconsistent.
- Requires improvement: exceeds 10 minutes or uses incorrect format; disorganized, hard to follow, or omits major system functionalities.
- Unacceptable: missing video, or completely unwatchable; low quality, broken file, or lacks any meaningful explanation.
